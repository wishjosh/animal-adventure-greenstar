# Animal Adventure — 웹 게임

> 상태: 가로 화면용 실제 제품. 회색상자와 분리해 시작했으며 A–F 산촌 이동, 공통 입력, 세로 상태 보존, 로컬 저장·재개, A·B 손보기와 물주기, 자리별 환경 판단과 세 생물 행동을 구현하고 로그인 없이 열리는 공개 주소에 배포했다.

## 경계

- `../first-slice/`는 기존 행동 기준을 비교하는 동결된 회색상자다. 이 제품은 그 화면·입력·렌더 코드를 자동으로 제품 코드로 채택하지 않는다.
- 첫 지도 좌표와 이동 수치는 아직 플레이테스트용 제작값이다.
- A 정원 한 곳과 B의 두 흙자리에는 꽃·낮은 덮임·작은 흙 손보기, 이동·회수·복원과 흙자리별 되돌리기를 옮겼다. 나비류·달팽이류는 보호 자리와 알맞은 플레이어 편집물을 이용하고 피난했다가 다른 조용한 후보로 돌아온다. 무당개구리는 피난처의 잎·물결 단서 뒤 얕은 물가에 접근하고 같은 길로 물러났다 재방문한다.
- 저장 V1은 이 브라우저의 로컬 저장에 위치·시점·세계 시간과 현재 편집 배치만 남긴다. 동물의 단계·경로·방문 횟수·단서는 저장하지 않고, 새 페이지에서는 저장된 편집으로 후보를 다시 계산해 보호 자리와 피난처에서 시작한다. `이어 걷기` 전까지 세계는 정지하고 `방금 전` 이력은 새 페이지에 가져오지 않는다. 기기 간 클라우드 동기화는 아직 없다.
- 실제 플레이는 가로 화면 전용이며, 세로 상태에서는 진행과 동물·흔적 시간을 함께 멈추고 현재 모습을 보존한다.

## HTTPS에서 시험하기

- [산촌의 첫 물길](https://wishjosh.github.io/animal-adventure-greenstar/)을 Safari나 데스크톱 브라우저에서 연다. **로그인이 필요 없다.**
- [소유자용 ChatGPT Sites 주소](https://animal-adventure-first-waterway.wishbridge7.chatgpt.site)도 함께 유지한다. 이쪽은 `Continue with ChatGPT` 로그인이 필요하며 제작자가 빠르게 확인하는 용도다.
- 두 주소는 서로 다른 세계다. 저장은 주소와 브라우저 안에만 남으므로 한쪽의 진행이 다른 쪽으로 옮겨지지 않는다. 개발용 `localhost`도 마찬가지다.
- 아이폰은 회전 잠금을 끄고 가로로 돌린다. 세로에서는 세계를 멈춘 채 가로 전환 안내만 보이는 것이 정상이다.
- 아직 홈 화면 설치형 웹 앱, 오프라인 실행, 화면 방향 강제 잠금과 오디오는 지원하지 않는다.

## 배포

`main`에 올리면 [워크플로](.github/workflows/deploy-pages.yml)가 검사와 타입 검사를 돌린 뒤 GitHub Pages에 배포한다. 검사가 실패하면 배포하지 않는다.

- 검사는 `.mjs`에서 `.ts` 소스를 직접 불러오므로 타입 스트리핑이 기본으로 켜진 **Node 24 이상**이 필요하다. Node 20에서는 `ERR_UNKNOWN_FILE_EXTENSION`이 난다.
- `vite.config.js`의 `PAGES_BASE`는 저장소 이름과 같아야 한다. 저장소 이름을 바꾸면 여기도 바꾼다. 어긋나면 자산이 모두 `404`가 나고 흰 화면만 보인다.

## 실행과 검사

    npm.cmd install
    npm.cmd run dev
    npm.cmd test
    npm.cmd run check
    npm.cmd run build          # ChatGPT Sites용. 주소 최상위에서 서빙한다
    npm.cmd run build:pages    # GitHub Pages용. PAGES_BASE를 자산 경로에 붙인다

## 현재 조작

- 휴대폰: 왼쪽 이동 패드로 걷고 오른쪽 화면을 끌어 둘러본다.
- 컴퓨터: WASD·방향키로 걷고 화면을 끌어 둘러보며 휠로 거리를 바꾼다.
- 관리된 흙자리 가까이에서 `가꾸기`를 누른다. 한 줄 도크에 `심기`·`물주기`·`덮어 주기`·`흙 북돋우기`와 `되돌리기`·`걷기로`가 있다. 도구를 다시 누르면 내려놓는다.
- 이미 심어 둔 것은 도구와 상관없이 그냥 누르면 잡힌다. 잡은 뒤에 `옮겨심기`·`캐서 담기`를, 북돋운 흙에는 `원래 흙으로`를 쓸 수 있다. 겹쳐 놓기는 원래 막혀 있으므로 별도의 `고르기` 도구를 두지 않는다.
- A 정원 옆 우물이나 B 개울에 다가가면 `물 뜨기`가 나타난다. 한 번 채운 물뿌리개로 네 자리를 적신다. 물을 준 흙은 맨 흙이면 3분, 덮은 곳이면 8분쯤 지나 마르고 그늘과 덮임이 겹치면 한 세션 안에 거의 마르지 않는다. 물주기는 되돌리기와 저장의 대상이 아니다.
- 컴퓨터에서는 `Space`로 가꾸기에 들어가고 `Escape`로 잡은 것·옮겨심기·가꾸기를 차례로 취소하며 `Z`로 방금 한 것을 되돌린다.
- 기기나 창이 세로가 되면 가로 전환 안내가 나타나며, 돌아오면 같은 자리에서 이어진다.

## 현재 검증

- 지도·입력·런타임·편집·국소 환경·표면 습기·물뿌리개·저장·세 생물 행동과 HTTPS 경로 응답 자동 검사 107개, TypeScript 검사와 제품 빌드가 통과한다.
- 작은 주민은 아직 자기 자리가 없는 흙을 들러 잠시 살피고 그냥 돌아간다. 목표나 과제를 글로 제시하지 않고 `여기에 무언가 있으면 좋겠다`만 행동으로 보여 주는 장치다. 살피기와 실제 이용을 번갈아 하며, 플레이어가 그 자리를 채우면 살필 곳이 없어져 저절로 사라진다. 실패 표시·슬픈 연출·점수는 붙이지 않는다.
- 표면 습기는 자리마다 고정된 값이 아니라 시간에 따라 마르는 값이다. 젖음과 마름이 실제로 뒤바뀐 순간에만 국소 환경을 다시 판정하며 매 프레임 재판정하지 않는다는 것을 검사로 고정했다.
- 데스크톱 브라우저에서 나비류·달팽이류의 보호 자리 이용, 무당개구리의 늦은 물가 이용과 연속 피난, 저장 후 재접속의 세계 복원·동물 초기화, 명시적 `새로 걷기`를 확인했다. `667×375`·`844×390`·`932×430` 가로 화면에는 넘침이 없었고, 세로 전환 중 세계와 세 생물 상태가 멈췄다가 가로 복귀에서 이어졌다.
- 두 번째 HTTPS 배포에서 첫 화면과 별도 HTML 경로, JavaScript와 CSS가 모두 정상 응답하고 `application/json`으로 요청한 없는 경로는 `404`를 유지하는 것을 확인했다.
- GitHub Pages 배포에서 첫 화면과 자산이 `PAGES_BASE` 경로로 정상 응답하는 것을 확인했다.
- 우물·개울과 물뿌리개, 물 준 흙의 색 변화는 실제 화면에서 아직 눈으로 확인하지 않았다. 우물의 크기·비례와 젖은 흙의 대비는 보정이 필요할 수 있다.
- 이 프로젝트에는 충돌 판정이 없다. 집·나무·우물을 통과해 걸어진다.
- 실제 아이폰 Safari와 안드로이드 Chrome의 두 손 터치·안전 영역·백그라운드 복귀·장시간 성능은 아직 검증하지 않았다.
